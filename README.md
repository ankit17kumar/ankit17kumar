## 🧭 What I've learned leading with AI

- **Agents are systems.** Clear roles, contracts and failure paths matter more than clever prompts.
- **Ground everything.** If a number can't be traced to a source, it doesn't ship.
- **Measure before you polish.** A prompt fix without a golden dataset is a guess.
